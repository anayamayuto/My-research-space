# VR Lecture Space (VR授業動画鑑賞空間)

A-FrameとMediaPipeを活用し、VR空間内で講義動画を視聴しながら、学習者の姿勢や集中度をリアルタイムでトラッキング・分析するWebアプリケーションです。OpenAI APIを活用した音声文字起こしや、概念の図解生成機能も備えており、学習を多角的にサポートします。

## 🌟 主な機能

- **VR没入型学習空間**: A-Frameによる3D空間で動画講義を視聴。
- **リアルタイム姿勢トラッキング**: WebカメラとMediaPipeを利用し、学習者の姿勢（肩の傾き、頭の前傾、上半身の傾きなど）や視線を分析。
- **データエクスポート機能**: 収集した姿勢・視線・表情データをAI学習用のJSONL形式やCSV形式でエクスポート可能。
- **AI学習サポート機能**:
  - **音声文字起こし**: Whisper APIを利用し、音声ファイルから高精度な文字起こしを生成。
  - **日常メタファー図解生成**: DALL-E 3を使用し、難しい学習概念を日常の出来事に例えた図解を自動生成。

## 🛠 技術スタック

- **フロントエンド**: HTML, CSS, JavaScript, A-Frame (WebVR), MediaPipe
- **バックエンド**: Node.js, Express
- **動画・音声処理**: FFmpeg, Fluent-FFmpeg, Multer
- **AI・外部API**: OpenAI API (Whisper, GPT-4o-mini, DALL-E 3)

## 📋 動作環境・前提条件

- **Node.js** (推奨バージョン: v16以降)
- **FFmpeg**: 依存パッケージとして `ffmpeg-static` がインストールされますが、システムにインストールされているとより安定します。
- **OpenAI API Key**: AI機能を利用するために必要です。

## 🎮 起動・使用方法

1. サーバーを起動します。

```bash
npm start
```

2. ブラウザで以下のURLにアクセスします。
   - `http://localhost:3000/` または `http://localhost:3000/lecture`

3. **学習の開始**:
   - 画面左上のコントロールパネルから、視聴したい講義動画（MP4等）を選択します。
   - 必要に応じて字幕ファイル（VTT）を選択します。
   - 「再生」ボタンをクリックしてVR空間での講義を開始します。

4. **姿勢トラッキング**:
   - 「姿勢トラッキング開始」ボタンを押すと、Webカメラが起動し、姿勢の分析が開始されます。
   - VR空間右側に表示される「POSTURE ANALYTICS」パネルにスコアがリアルタイムで反映されます。

## 📁 ディレクトリ構成

- `server.js` - バックエンドサーバーのメインファイル
- `lecture.html` - VR講義空間のフロントエンドHTML
- `lecture-client.js` - フロントエンドのロジック（A-Frame制御、MediaPipe姿勢推定など）
- `lecture.css` - フロントエンドのスタイリング
- `pose_data/` - トラッキングされた姿勢データの保存先
- `uploads/` - アップロードされた音声・動画ファイルの一時保存先
