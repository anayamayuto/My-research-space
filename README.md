# AI先生 ― VR授業空間で、学びを見守るAI

VR空間で講義動画を視聴する学習者の状態を、Webカメラの映像からリアルタイムに推定し、状況に応じて声をかけるWebアプリケーションです。

オンライン授業では、対面のように教室の空気や一人ひとりの反応を読み取ることが難しく、「困っている」「集中が切れた」といった無意識のサインが講師に伝わりにくいという課題があります。本プロジェクトでは、姿勢・視線・表情・手の動きを数値データに変換し、機械学習で学習者の状態を推定することで、この「見えない学習状態」を可視化し、自動的な声かけにつなげることを目指しています。

> 武蔵野大学 データサイエンス学部 中村研究室での研究成果物です（個人開発）。

## 🌟 主な機能

### 学習者の状態推定と声かけ（AI先生）
- WebカメラとMediaPipeで顔・体の特徴点を検出し、**11個の特徴量**（姿勢・頭の向き・表情・手）に変換
- ニューラルネットワークで **5つの状態** を推定し、状態が数秒続いたときに声をかけます

  | 状態 | 判定の目安 | AI先生の反応 |
  |---|---|---|
  | 困惑 | 顔を触る・眉をひそめる（3秒継続） | 「少し難しい？」＋10秒巻き戻しボタン |
  | よそ見 | 顔を横に大きく向ける（5秒継続） | 動画を一時停止して休憩を提案 |
  | 姿勢不良 | 姿勢スコアの低下（5秒継続） | 「背筋を伸ばしてみよう」 |
  | 集中 | 背筋が伸び画面を見続ける（15秒継続） | 「素晴らしい集中力！」と称賛 |
  | 通常 | 上記以外 | 反応なし |

- **ライブモニター**：5状態の確率バーをリアルタイム表示し、AIが何を根拠に判定しているかを一目で確認できます

### 眠気の予測（開発中）
- 直近60秒の時系列から、PERCLOS（閉眼率）・まばたき・あくび・頭の落下（ノッド）など10個の特徴量を算出
- 開始時の45秒で個人の平常時を計測し、人・照明・カメラ位置が変わっても壊れにくい判定に
- 眠気スコアが上がり続けると、動画を止めて休憩を提案

### 学習サポート機能
- **音声文字起こし**：Whisper APIで講義音声を文字起こし
- **日常メタファー図解**：難しい概念を身近な出来事に例えた図解をDALL-E 3で生成

## 🔒 プライバシーへの配慮

カメラ映像は**保存も外部送信もしません**。映像から計算した数値だけを扱い、推論はすべてブラウザ内（TensorFlow.js）で完結します。「監視」ではなく、学びをそっと支える道具であることを大切にしています。

## 🧠 開発の経緯と工夫

### STEP 1：ルールベースで試作
まず機械学習を使わず、「顔を横に25°以上向けたら よそ見」「姿勢スコア60未満なら 姿勢不良」といったしきい値で判定し、動くものを素早く作りました。しかし、座り方の個人差に弱い、複合的な状態を捉えられない、しきい値付近で判定が細かく反転する、といった限界が見えました。

### STEP 2：機械学習化
ルールベースの判定器を**正解ラベルの自動生成器**として使い、34セッション・約5,800サンプルの学習データを作成。小さなニューラルネットワーク（11 → 32 → 16 → 5）をPythonで学習し、TensorFlow.jsに変換してブラウザで動かしています。

### STEP 3：「精度97%なのに本番で暴走」した問題の解決
テスト精度は97%でしたが、実際に使うと普通に画面を見ているだけで「困惑」と判定され続け、10秒巻き戻しが連発しました。原因を切り分けた結果、次の3つが分かりました。

| 原因 | 内容 |
|---|---|
| 常に0の特徴量 | 学習時は頭の前傾スコアがずっと0。本番で値が入った途端、正規化後に異常値となり判定を支配していた |
| 角度の±180°問題 | 頭の傾きが +177° ⇔ −177° で符号反転し、「符号が変＝困惑」と誤って学習していた |
| データの偏り | ほぼ1回分の座り姿勢しかなく、「よそ見」「居眠り」の実演データが1件もなかった |

これに対し、次の改善を行いました。

- 不要な特徴量を外し、角度を **sin/cos** で表現（12 → 11特徴量）
- 正規化後の値を **±3でクリップ** し、学習範囲外の入力による暴走を防止
- 確率 **0.7未満** の予測は「通常」として扱い、誤発火を抑制
- **直近2秒の多数決** で判定を平滑化
- 推論を **30fps → 5fps** に間引いてブレを抑制
- 似たフレームが訓練とテストに混ざらないよう **時系列で分割** して評価
- クラス重み付き学習と、クラス別recallの確認

**学び**：テストの数字よりも、「学習時と本番の入力のズレ」と「データの質」が大事。

## 🎮 起動方法

### 必要なもの
- Node.js（v16以降）
- Webカメラ付きのPC
- OpenAI APIキー（文字起こし・図解生成を使う場合のみ）

### 手順

```bash
npm install
# 文字起こし・図解生成を使う場合のみ
echo "OPENAI_API_KEY=sk-..." > .env
npm start
```

ブラウザで以下にアクセスします。

| URL | 内容 |
|---|---|
| `http://localhost:3000/lecture-ml` | **AI先生（機械学習版）** ― メイン |
| `http://localhost:3000/lecture` | ルールベース版 |

1. 画面左上のパネルから講義動画（MP4など）を選び、再生します
2. 「姿勢トラッキング開始」を押すとカメラが起動し、状態推定が始まります
3. 画面右のライブモニターで、5状態の確率がリアルタイムに動きます

学習済みモデルは `public/model/` に同梱しているので、そのまま動きます。

### モデルの再学習（任意）

```bash
cd ml
pip install tensorflow tensorflowjs scikit-learn pandas
python train.py          # 状態推定モデル
python train_drowsy.py   # 眠気予測モデル
```

学習データは `/lecture-ml` で数字キー（0〜4）を押しながら各状態を演じると `annotation_data/dataset.csv` に記録されます。詳しい手順は [ML_FIX_README.md](./ML_FIX_README.md)、眠気モデルは [DROWSY_GUIDE.md](./DROWSY_GUIDE.md) を参照してください。
